# AI深度伪造风险识别与校园反诈体验系统

## 一、项目概述

这一项目实际上是一依托于 HTML、CSS 以及 JavaScript 来进行开发的 AI 伦理教育互动网页，其主题正是“AI深度伪造风险识别与校园反诈体验系统”，它给带来了一种全新的学习体验。

该项目主要是面向高校学生的校园生活情景，它给大家带来了很多实用功能，围绕着AI换脸、语音复制、虚假兼职、伪造老师通知、冒充熟人汇款等诸多隐患问题，通过一系列举措，构建了诈骗情况分析、普通情景仿真、纵深伪造辨认自测、校园反诈建议以及AI伦理知识卡片等实用功能，从而能更好地保障学生在校园生活中的安全。

## 二、项目功能

1. 诈骗情况分析助手  
用户在使用系统的时候，能够把自己所遇到的可疑情况输入进去，系统会对隐患等级、可疑详情、处理建议以及核实方法进行分析，从而体现出其对用户问题的有效应对。

2. 普通 AI 诈骗情景仿真  
该系统通过展示多种情景，包括AI换脸冒充朋友借钱的情况、AI语音冒充辅导员要求缴费的状况，以及AI生成兼职骗局等类似的情景，从而体现出当下AI可能带来的各类风险。

3. 纵深伪造辨认自测  
用户勾选可疑线索，系统判断是不是存在纵深伪造或者诈骗隐患。

4. 校园反诈处理建议生成器  
根据用户选择的问题类型，生成对应处理建议。

5. AI伦理知识卡片  
介绍纵深伪造、AI换脸、语音复制、隐私保护和学术守信等概念。

## 三、技术栈

- HTML：负责页面结构
- CSS：负责页面样式
- JavaScript：负责互动逻辑、隐患分析和结果显示

## 四、运行方法

1. 下载项目资料夹；
2. 找到 `index.html` 文件；
3. 双击 `index.html`；
4. 使用浏览器打开网页；
5. 输入情况描绘或者选择功能模块实施测验。

## 六、项目特色

这一项目与普通的校园问答网页有所不同，它给人一种独特的感觉，其核心是集约了AI纵深伪造以及校园反诈方面的问题，用户可以使用自然语言来详细地描绘自己所面临的情况，当时的系统会根据这些描绘，有效地辨认出诸如汇款、证实码、二维码、AI换脸、紧急敦促、保密要求等隐患点，并且会给出相应的核实方法。
